# きづきの診断

親・子ども・大学生が同じ8つの質問に答え、選びかたの違いや「大人の予想」と「子ども本人」のずれをくらべる診断ツールです。サーバー不要の静的サイトなので、そのまま公開できます。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 診断ページ（公開するのはこれ） |
| `config.js` | 集計先のURLなどの設定 |
| `aggregate.html` | 各端末で保存したExcelファイルを1つにまとめる集計ページ |
| `gas/Code.gs` | 回答を Google スプレッドシートに貯める Apps Script |

## 1. 公開する

### GitHub Pages（このリポジトリから）
1. GitHub の **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチを公開したいブランチ・フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

> リポジトリが **private** の場合、GitHub Pages は有料プラン（Pro 以上）が必要です。無料で公開するにはリポジトリを public にするか、下の方法を使ってください。

### そのほかの方法
フォルダごと [Netlify Drop](https://app.netlify.com/drop) にドラッグする、または Cloudflare Pages / Vercel などに置くだけでも公開できます。

### グループ名（イベント名）をつける
URLの末尾に `?g=名前` を付けると、その名前が回答に記録されます。
例：`https://…/index.html?g=10月ワークショップ`
会場や回ごとにURL（QRコード）を分けておくと、あとで絞り込みやすくなります。

## 2. 回答を集計する

方法は2つあります。どちらか一方でも、両方でも使えます。

### A. Google スプレッドシートに自動で集める（おすすめ）
回答した瞬間に1人1行でシートに追記され、「集計」シートに回答者別（親・子ども・大学生・全体）の平均が自動で出ます。

1. Google ドライブで新しいスプレッドシートを作る
2. **拡張機能 → Apps Script** を開き、`gas/Code.gs` の中身をすべて貼り付けて保存
3. **デプロイ → 新しいデプロイ** → 種類の選択で「ウェブアプリ」
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**全員**
4. 権限の確認を許可し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー
5. `config.js` の `sheetUrl: ''` の `''` の中に貼り付けて保存・公開し直す

**Excelで使うとき**：スプレッドシートで **ファイル → ダウンロード → Microsoft Excel (.xlsx)**。

> `Code.gs` を書き換えたときは「デプロイを管理」から**新しいバージョン**でデプロイし直してください（URLは変わりません）。

### B. 端末ごとにExcelで保存して、あとでまとめる
集計シートを用意しなくても使えます。

1. 回答後、「くらべる」タブの **Excelで保存する** を押す（その端末で答えた全員分が1ファイルに入ります）
2. 集まったファイルを `aggregate.html`（集計ページ）にまとめてドロップ
3. **まとめたExcelを保存する** で、「回答」（全員分）と「集計」（回答者別の平均・タイプ別人数）の2シートを持つExcelができます

同じ回答が重複して読み込まれても、回答IDで1件にまとめられます。ファイルはブラウザ内だけで処理され、外部には送られません。

## Excel の列

| 列 | 内容 |
| --- | --- |
| 回答日時・グループ | 回答した日時、`?g=` で指定したグループ名 |
| セッションID | 同じ端末・同じ回で答えた人に共通。親子の回答をつなげるのに使う |
| 回答ID | 1人の回答ごとのID（再送信・重複の判定用） |
| 回答者 | 親 / 子ども / 大学生 |
| タイプ・サブタイプ | 診断タイプ（子どもも大人向けの名前で記録） |
| 柔軟度・各スコア | 0〜100。「流されやすさ」は高いほど周囲に合わせる傾向（柔軟度では逆向き） |
| 回答の一貫性 | 高い / ふつう / 低め / 全問同じ回答 |
| Q1〜Q8 | 3者共通の質問の素点（1=ちがう 〜 4=そう） |
| 子どもの予想Q1〜Q8 | 親・大学生が予想した子どもの答え（1〜4） |
| 予想の一致数 | 同じ回の子ども本人の答えと一致した数（8問中） |
| S1〜S4・サポーター適性 | 大学生のみ |
| 気づいたこと | 結果画面の自由記述 |

## プライバシー
名前・メールアドレスなど個人を特定する情報は集めません。送られるのは上の表の項目だけです。自由記述に個人情報を書かないよう、案内の際に一言添えてください。
