# きづきの診断

自分が「教育」や「選ぶこと」に対してどんな価値観を持っているかに気づくための診断ツールです。子育て経験のある方・子育て経験のない方（高校生以下）・子育て経験のない方（大学生以上）が、身近な場面でのふりかえり（A〜Dの選択）と同じ8つの質問に答え、考え方の違いや「大人の予想」と「高校生以下の方の答え」のずれをくらべます。サーバー不要の静的サイトなので、そのまま公開できます。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 診断ページ（公開するのはこれ） |
| `config.js` | 集計先のURLなどの設定 |
| `aggregate.html` | 各端末で保存したExcelファイルを1つにまとめる集計ページ |
| `gas/Code.gs` | 回答を Google スプレッドシートに貯める Apps Script |

## 1. 公開する

### GitHub Pages（このリポジトリから）
1. GitHub の **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチを公開したいブランチ・フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

> リポジトリが **private** の場合、GitHub Pages は有料プラン（Pro 以上）が必要です。無料で公開するにはリポジトリを public にするか、下の方法を使ってください。

### そのほかの方法
フォルダごと [Netlify Drop](https://app.netlify.com/drop) にドラッグする、または Cloudflare Pages / Vercel などに置くだけでも公開できます。

### グループ名（イベント名）をつける
URLの末尾に `?g=名前` を付けると、その名前が回答に記録されます。
例：`https://…/index.html?g=10月ワークショップ`
会場や回ごとにURL（QRコード）を分けておくと、あとで絞り込みやすくなります。

## 2. 回答を集計する

方法は2つあります。どちらか一方でも、両方でも使えます。

### A. Google スプレッドシートに自動で集める（おすすめ）
回答した瞬間に1人1行でシートに追記され、「集計」シートに回答者別（3つの立場・全体）の平均が自動で出ます。

1. Google ドライブで新しいスプレッドシートを作る
2. **拡張機能 → Apps Script** を開き、`gas/Code.gs` の中身をすべて貼り付けて保存
3. **デプロイ → 新しいデプロイ** → 種類の選択で「ウェブアプリ」
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**全員**
4. 権限の確認を許可し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー
5. `config.js` の `sheetUrl: ''` の `''` の中に貼り付けて保存・公開し直す

**グラフで傾向を見る（分析シート）**：`Code.gs` を貼り付けたあとスプレッドシートを開き直すと、メニューに「きづきの診断」が出ます。**きづきの診断 → シートをまとめて作る（集計・回答・分析）** を1回実行すると、「集計」「回答」「分析」の3シートがこの順にできます（回答がまだ0件でも作れます。回答シートのデータは残ります）。「分析」シートには次の表とグラフが入ります。すべて数式なので、回答が増えると自動で更新されます。B2 のプルダウンでグループ（イベント）ごとに絞り込めます。

1. 回答者別の平均スコア（4つの視点と柔軟度）
2. 質問ごとの平均（3つの立場）
3. 高校生以下の方の答えと、子育て経験あり・大学生以上の方の予想のくらべ（予想の一致数の平均も）
4. タイプの割合（回答者別）
5. 柔軟度の分布
6. ふりかえり（場面1〜3）で選んだ行動 A〜D の割合
7. 高校生以下の学年別（小学生・中学生・高校生）の平均スコア
8. アンケート：自分の現状への気づき・理解（立場別の平均・割合と、目標に届いたかの判定）
9. 予想の一致数と子どもへの理解の関係
10. 自由記述の分類基準

## 診断のあとのアンケート
結果画面の下に、自分の今の状態にどれくらい気づけたか・理解できたかを聞くアンケートがあります（約2分）。答えは同じ回答の行に追加され、「分析」シートの 8・9 に集計されます。

- **大人（子育て経験あり・大学生以上）**：結果への納得感（B1・B2）、自分への気づき（C1〜C4）、子どもへの理解（D1〜D4）、これからの行動（E1・E2、大学生以上はE3も）、自由記述（F1 必須、F2・F3 任意）
- **高校生以下**：K1〜K4 と自由記述
- **指標**：納得感・自分への気づき・子どもへの理解・行動意思は0〜100。気づきの伸び＝C2−C1（診断前をふりかえって答えてもらう事前・事後比較）。思い込みへの気づき＝D1・D2がどちらも3以上。
- **自由記述の分類**：回答シートの黄色の列「自由記述の分類（0〜2・チーム入力）」に、分析シート下部の基準で 0・1・2 を入力すると「具体的な気づきがあった人の割合」が出ます。この列はページから再送信があっても上書きされません。
- **目標**：分析シートの黄色のセル（仮置き）を書き換えると、達成／未達の判定が変わります。

**Excelで使うとき**：スプレッドシートで **ファイル → ダウンロード → Microsoft Excel (.xlsx)**。

> `Code.gs` を書き換えたときは「デプロイを管理」から**新しいバージョン**でデプロイし直してください（URLは変わりません）。

### B. 端末ごとにExcelで保存して、あとでまとめる
集計シートを用意しなくても使えます。

1. 回答後、「くらべる」タブの **Excelで保存する** を押す（その端末で答えた全員分が1ファイルに入ります）
2. 集まったファイルを `aggregate.html`（集計ページ）にまとめてドロップ
3. **まとめたExcelを保存する** で、「回答」（全員分）と「集計」（回答者別の平均・タイプ別人数）の2シートを持つExcelができます

同じ回答が重複して読み込まれても、回答IDで1件にまとめられます。ファイルはブラウザ内だけで処理され、外部には送られません。

## Excel の列

| 列 | 内容 |
| --- | --- |
| 回答日時・グループ | 回答した日時、`?g=` で指定したグループ名 |
| セッションID | 同じ端末・同じ回で答えた人に共通。家族やグループの回答をつなげるのに使う |
| 回答ID | 1人の回答ごとのID（再送信・重複の判定用） |
| 回答者 | 子育て経験のある方 / 子育て経験のない方（高校生以下） / 子育て経験のない方（大学生以上） |
| 学年（高校生以下） | 高校生以下の方が最初に選んだ学年（小学生・中学生・高校生） |
| タイプ・サブタイプ | 診断タイプ（高校生以下の方も大人向けの名前で記録） |
| 場面1〜3 | ふりかえりで選んだ行動。A=自分で考えて決める / B=身近な人を参考にする / C=まず試してみる / D=周りに合わせる |
| 柔軟度・各スコア | 0〜100。「流されやすさ」は高いほど周囲に合わせる傾向（柔軟度では逆向き） |
| 回答の一貫性 | 高い / ふつう / 低め / 全問同じ回答 |
| Q1〜Q8 | 3者共通の質問の素点（1=ちがう 〜 4=そう） |
| 子どもの予想Q1〜Q8 | 子育て経験あり・大学生以上の方が予想した子どもの答え（1〜4） |
| 予想の一致数 | 同じ回の高校生以下の方の答えと一致した数（8問中） |
| S1〜S4・サポーター適性 | 大学生以上のみ |
| 気づいたこと | 結果画面の自由記述 |

## プライバシー
名前・メールアドレスなど個人を特定する情報は集めません。送られるのは上の表の項目だけです。自由記述に個人情報を書かないよう、案内の際に一言添えてください。
